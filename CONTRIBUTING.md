# Mitwirken

Dieses Repository ist derzeit ein unveröffentlichter Projektentwurf.

Vor Änderungen bitte:

1. keine WLAN-Zugangsdaten einchecken,
2. generierte EEZ-Dateien und lokale Anpassungen nachvollziehbar dokumentieren,
3. Hardware- und Bibliotheksversionen bei Fehlerberichten angeben,
4. Änderungen zunächst in einem separaten Branch vornehmen.
